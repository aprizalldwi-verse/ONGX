## 1. PRODUK

**Nama:** ONGX
**Tagline:** `Nonton tanpa ribet.`
**Posisi:** Portal streaming agregator dua-vertikal:
- **ONGX JAV** — katalog Jepang (sumber: missav)
- **ONGX FILM** — film, series, anime, drama (sumber: idlix)

**Model bisnis:** 100% iklan (Monetag). Tanpa login wajib. Tanpa paywall.
**Pengguna:** mobile-first, mayoritas Android, jaringan 3G/4G tidak stabil, datang dari Google & social.

**Non-goal v1:** komentar, login OAuth, aplikasi native, subtitle upload sendiri, transcode video.

## 2. SUMBER DATA

### 2.1 Upstream A — missav
- Base: `https://missav.live`
- Listing: `/{lang}` , `/{lang}/new` , `/{lang}/release` , `/{lang}/uncensored-leak` , `/{lang}/today-hot`
- Detail: `/{lang}/{code}` (code lowercase, mis. `dldss-583`)
- Taksonomi: `/{lang}/genres` , `/{lang}/actresses` , `/{lang}/makers`
- Cover: `https://fourhoi.com/{code}/cover-t.jpg` (thumb), `cover.jpg` (besar)
- Stream: HLS `.m3u8` di `surrit.com`, UUID diekstrak dari HTML detail.
- Tanpa API resmi. **Cloudflare aktif.**

### 2.2 Upstream B — idlix
- Base: `https://z2.idlixku.com`
- Listing: `/movie` , `/series` , `/genre/{g}` , `/country/{c}` , `/year/{y}`
- Detail: `/movie/{slug}` , `/series/{slug}`
- Data: JSON internal `/api/movies`, `/api/series`, `/api/search?q=`
- Stream: gate token → redeem → `majorplay.net/*.json` (`.m3u8` + `.vtt`). Delay gate 15 detik.
- **Cloudflare TLS-fingerprint blocking.** `fetch()` Node biasa kena 403. Butuh stealth browser.
- Referensi implementasi: `github.com/annurdien/IDLIX-API` (MIT). Boleh dijadikan acuan, tulis ulang agar sesuai arsitektur kita.

### 2.3 Aturan integrasi
- Normalisasi semua entitas ke skema internal (§5). Upstream ID hanya disimpan di `ExternalRef`.
- **Jangan** tampilkan iframe upstream sebagai satu-satunya cara nonton. Wajib ada dua tier:
  - **Tier 1 (default):** player sendiri, HLS.js + `m3u8` hasil resolve, kontrol kualitas, subtitle `.vtt`, resume posisi.
  - **Tier 2 (fallback):** iframe `/{lang}/{code}` atau `?play=1` bila resolve gagal / CORS / 403.
- Semua gambar lewat proxy `/_img?src=` (whitelist domain) + `sharp` resize + `Cache-Control: public, max-age=604800, immutable`. Anti-hotlink.
- Rate limit per IP ke upstream: 60 req/menit. Backoff eksponensial 3x. User-Agent rotasi dari pool 5 UA desktop modern.
- Hormati `robots.txt` upstream untuk area yang tidak kita crawl.

## 5. SKEMA DATABASE (Prisma)

Buat persis, boleh tambah index:

```prisma
enum Source { MISSAV IDLIX }
enum Kind   { JAV MOVIE SERIES EPISODE }
enum Status { DRAFT LIVE BROKEN GONE }

model Title {
  id           String   @id @default(cuid())
  source       Source
  kind         Kind
  status       Status   @default(DRAFT)
  slug         String   @unique
  code         String?  @unique          // JAV code
  titleNative  String?
  titleId      String?
  titleEn      String?
  synopsis     String?
  year         Int?
  releasedAt   DateTime?
  durationSec  Int?
  rating       Float?
  posterUrl    String
  backdropUrl  String?
  trailerUrl   String?
  maker        String?
  director     String?
  country      String?
  language     String?
  isUncensored Boolean  @default(false)
  hasSubEn     Boolean  @default(false)
  hasSubId     Boolean  @default(false)
  views        Int      @default(0)
  score        Float    @default(0)      // untuk ranking
  refs         ExternalRef[]
  genres       TitleGenre[]
  people       TitlePerson[]
  episodes     Episode[]  @relation("Series")
  parent       Title?     @relation("Series", fields: [parentId], references: [id])
  parentId     String?
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt

  @@index([source, status, kind, score])
  @@index([status, releasedAt])
}

model ExternalRef {
  id       String @id @default(cuid())
  titleId  String
  title    Title  @relation(fields: [titleId], references: [id], onDelete: Cascade)
  provider Source
  remoteId String
  url      String
  @@unique([provider, remoteId])
}

model Episode {
  id        String @id @default(cuid())
  seriesId  String
  series    Title  @relation("Series", fields: [seriesId], references: [id], onDelete: Cascade)
  season    Int
  number    Int
  titleId   String? @unique
  @@unique([seriesId, season, number])
}

model Person { id String @id @default(cuid()); slug String @unique; name String; imageUrl String?; titles TitlePerson[] }
model TitlePerson { titleId String; personId String; role String; @@id([titleId, personId, role]) }
model Genre  { id String @id @default(cuid()); slug String @unique; nameId String; nameEn String; titles TitleGenre[] }
model TitleGenre { titleId String; genreId String; @@id([titleId, genreId]) }

model StreamSource {
  id        String @id @default(cuid())
  titleId   String
  label     String   // "720p", "1080p", "auto"
  url       String
  type      String   // "hls"
  expiresAt DateTime?
  @@index([titleId])
}

model Subtitle { id String @id @default(cuid()); titleId String; lang String; url String }

model CrawlJob { id String @id @default(cuid()); source Source; cursor String?; phase String; ok Boolean @default(true); error String?; startedAt DateTime @default(now()); finishedAt DateTime? }

model Report { id String @id @default(cuid()); titleId String; reason String; note String?; ip String; createdAt DateTime @default(now()) }
```

## 9. MESIN IKLAN (MONETAG) — PALING KRITIS

Arsitektur **config-driven**. Zona tidak boleh tersebar di komponen.

`src/config/ads.ts`:

```ts
export const AD_ZONES = {
  smartTag:    { enabled:true,  zoneId: env.NEXT_PUBLIC_MT_SMART },
  inPagePush:  { enabled:true,  zoneId: env.NEXT_PUBLIC_MT_PUSH },
  vignette:    { enabled:true,  zoneId: env.NEXT_PUBLIC_MT_VIGNETTE },
  interstitial:{ enabled:true,  zoneId: env.NEXT_PUBLIC_MT_INTERSTITIAL },
  popunder:    { enabled:true,  zoneId: env.NEXT_PUBLIC_MT_POPUNDER },
  rewarded:    { enabled:true,  zoneId: env.NEXT_PUBLIC_MT_REWARDED },
  native:      { enabled:true,  zoneId: env.NEXT_PUBLIC_MT_NATIVE },
} as const;
```

Aturan implementasi:

1. **`<AdProvider>`** di root layout: `next/script` `strategy="lazyOnload"` untuk smart tag + push + vignette. Satu kali, jangan duplikat.
2. **`<AdSlot variant>`** menyediakan 3 varian: `inline` (di antara rail, tiap 2 rail, maks 6 per halaman), `in-grid` (setiap 7 kartu), `sticky-footer`. Semua punya **tinggi terkunci** (250/300/100) → CLS 0. Render `<div>` kosong + `data-zone` bila `enabled=false` (dev).
3. **Interstitial** dipicu sekali per sesi, hanya pada navigasi ke `/watch/*` dan hanya jika `document.referrer` internal + sudah scroll > 1 viewport. Simpan flag `sessionStorage.ongx_int`.
4. **Popunder** baru diaktifkan setelah gesture pertama (`pointerdown` sekali) agar tidak bentrok dengan autoplay.
5. **Rewarded** opsional di player: tombol "Tonton iklan → buka 1080p". Setelah resolve, unlock kualitas tinggi 30 menit di `sessionStorage`.
6. **Jangan pasang iklan di dalam `<iframe>` player.** Pause/mute state disimpan; setelah interstitial tertutup, resume posisi.
7. **Anti-CLS + anti-blocker:** `<noscript>` berisi placeholder gambar. Deteksi adblock ringan; bila terdeteksi tampil baris "Matikan adblock untuk bantu ONGX".
8. `/ads.txt` di-serve route handler statis berisi baris `monetag` (isi placeholder `# TODO`).
9. Semua slot punya `data-slot-id` unik untuk A/B nanti.
10. Di dev, semua slot render kotak bergaris + label zona agar mudah diverifikasi visual.

## 10. SEO

- `generateMetadata` per halaman: title `<Judul> — ONGX`, deskripsi 150–160 char, canonical absolut, `hreflang` id/en/x-default.
- JSON-LD: `Movie`/`TVSeries`/`TVEpisode` + `VideoObject`, `BreadcrumbList`, `WebSite` + `SearchAction`, `Person` untuk aktris.
- OG image dinamis via `opengraph-image.tsx` (poster + wordmark, 1200x630).
- Sitemap terpecah, `lastmod` dari `updatedAt`, maks 45k URL per file, exclude status `BROKEN`.
- `robots.txt`: allow semua kecuali `/admin`, `/api`; blokir `GPTBot`? tidak, biarkan.
- Slug SEO: `{code}-{slug-judul}` untuk JAV, `{judul}-{tahun}` untuk film. Simpan mapping lama → 301.
- Internal linking: setiap detail wajib 12 related + rail genre + breadcrumb.
- `noindex` untuk halaman hasil search & paginasi > 20.

## 11. PERFORMA

- RSC untuk semua data fetch. Client component hanya player, filter, search, ads.
- `revalidate = 1800` pada detail, `600` pada listing, `60` pada home.
- Poster: `next/image` `sizes` sesuai grid, `priority` hanya 3 kartu teratas di viewport awal, sisanya lazy.
- Streaming SSR + `Suspense` per rail, jangan blok render.
- Budget: JS awal ≤ 180 KB gzip. Bundle analyzer di CI, gagalkan bila lewat.
- Redis cache: resolve stream 15 menit, listing 10 menit, detail 30 menit.
- Cloudflare di depan Vercel: cache `/_img/*`, `/sitemap*.xml`, `/rss.xml` (edge, 1 hari).
- Preconnect: `fourhoi.com`, `surrit.com`, CDN Monetag.

## 12. KEAMANAN & LEGAL

- CSP ketat, `frame-ancestors 'self'`, `frame-src` whitelist (surrit, majorplay, missav, idlix, monetag).
- `Referrer-Policy: strict-origin-when-cross-origin`. Player iframe: `referrerPolicy="no-referrer-when-downgrade"`, `allow="autoplay; fullscreen; picture-in-picture; encrypted-media"`, `sandbox` tanpa `allow-same-origin` bila memungkinkan.
- Rate limit: 120 req/menit/IP pada `/api/*`, 20/menit pada `/api/report`.
- Validasi `src` gambar via Zod + whitelist host, cegah SSRF.
- `/dmca` berisi template takedown + email, `/privasi` menyebut cookie iklan pihak ketiga, `/syarat`.
- Halaman 18+ gate ringan: banner cookie/umur di first visit (`localStorage`), tidak memblok konten.
